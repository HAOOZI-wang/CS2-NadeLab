# NadeLab

**在 CS2 训练服中选目标、找投法、就位手投，再用真实结果验证。**

NadeLab 面向想研究道具的玩家、战队和社区。主要操作都在游戏窗口里完成：选择想封烟的地面或闪光爆点，记录出手站位，搜索经过地图碰撞检查的路线，自动回位、对准并切出道具，由你完成投掷。

**当前版本：0.2.0-rc.4，开源测试版，Windows 优先。** 支持六种道具、十张地图和八个测试假人。路线与效果模型仍在校准，复杂反弹可能漏搜；“找到路线”“实际命中”“效果达标”分别记录。适用范围是开启训练条件的本地或私人服务器。

这是源码仓库，源码 ZIP 不能直接当作玩家安装包运行。开发者可按[从源码构建](docs/development-guide.md)开始；玩家操作见下文及[玩家手册](docs/release/player-guide.md)。当前源码开放不代表全部功能已完成实投验收。

## 从这里开始

### 我想在自己的电脑上训练

1. 先关闭 CS2，将 Windows 工具包解压到**较短的全英文路径**，例如 `D:\NadeLab`；路径可含空格，不能含中文或其他非 ASCII 字符。
2. 双击 **`NadeLab.cmd`**，选择安装，按提示选择 CS2 安装目录和当前 Steam 账号。
3. 选择 **2 进入训练**；工具检查训练服就绪后，启动本地输入模块，通过 Steam 启动 CS2 并连接，不改个人键位文件。CS2 已经打开时，使用显示的控制台命令；选择 8 可仅启动训练服。
4. 进入地图，按 **F3** 选道具，按 **E** 选目标；到出手位置落地站稳，再按 **E** 搜索。
5. 有结果后按 **E** 就位，等准备完成，按屏幕提示手投。**R** 试下一种，**F1** 查看功能。

首次安装、依赖准备、更新与恢复见 [安装与恢复](docs/release/install-and-recovery.md)。拿到的是源码时，先由维护者构建发布包；源码中的开发启动脚本不是玩家安装入口。

首版已测试英文 Steam 游戏源路径；中文游戏源路径尚未验收。开发检查需要 .NET 10 SDK、Python 3 和 Windows PowerShell 5.1；`./scripts/build.ps1 -SourceOnly` 可在未安装 CS2 的电脑上编译及运行源码测试。制作可安装包还需要 CS2 Workshop Tools 编译与源码匹配的 UI，再运行完整构建。详见[开发指南](docs/development-guide.md)。

**源码工作区训练与调试：** 双击源码根目录的 `工作台.cmd`，可分别进入项目开发服与已安装的玩家工具，检查实例和插件文件，构建验证、安装开发插件及打开日志。工作台入口仅随源码提供，说明见 `docs/训练与调试.txt`；开发服与玩家安装服的数据各自独立。构建成功后仍需安装并重启对应实例才能验证新代码。

### 我已经有独立训练服务器

使用独立插件包，按 [服务器部署指南](docs/release/server-guide.md) 安装服务端插件和玩家端界面。玩家电脑不需要安装 .NET SDK 或编译界面。

## 能做什么

| 想做的事 | 游戏内入口 |
| --- | --- |
| 从指定站位反查投法 | F3 选道具 → E 选目标 → E 搜索 → E 就位 |
| 保留目标，换个出手位置 | 关闭菜单，到新位置停稳，Shift+R |
| 重新选目标 / 调整允许偏差 | Shift+E / F2 |
| 采用刚才手投的真实爆点 | F1 → 目标与站位 → 采用最近实投爆点 |
| 放置 / 管理假人及按要求寻闪 | F1 → 假人与寻闪 |
| 观察路线或预览效果 | V 飞行；F4 效果参考；F1 → 其他设置 → 显示设置 |
| 切换地图 | F1 → 切换地图 |

烟雾、T 燃烧瓶、CT 燃烧弹、诱饵用准星选地面；闪光、高爆手雷可变成道具模型飞到爆点，E 确认，F9 切第一/第三人称。搜索比较站投、蹲投、跳投、移动投等动作及左键、双键、右键力度；不会替你蓄力、起跳或松鼠标。

支持 Mirage、Dust2、Inferno、Nuke、Ancient、Anubis、Cache、Overpass、Train、Vertigo，游戏内只显示本实例已安装的地图。支持名单不代表每张图的全部路线已完成校准。
