## RC3 历史验证

2026-10-19：本轮修复受闪后假人自行转身。RC2 虽持续写回眼角，但机器人更新还会改变原生视角和身体朝向；原检查仅判断眼角，未覆盖这些独立状态。RC3 按实际偏差通过引擎纠正视角及身体朝向，通知客户端眼角变更，并清零转动速度，保留原生受闪动画。

| 检查 | 已有结果 | 解释边界 |
| --- | --- | --- |
| RC2 转身问题复现 | 743 帧中眼角最大误差 0°，身体最大误差 88.82553°，原生视角最大误差 89.90765°，新增朝向断言失败 | 证实仅检查眼角会漏掉实际转身 |
| RC3 初步方向回归 | 一轮 775 帧中眼角、身体及原生视角最大误差均为 0°，动画图实例未重建 | 属于初步服务端证据，不替代最终多朝向回归或客户端画面验收 |
| 最终四朝向真实闪光回归 | 四组各 11 项通过，每组采样 772 帧；俯仰/偏航为 (0°, 0°)、(25°, 137°)、(-25°, -179°)、(15°, 179°)。眼角及身体最大误差为 0°，原生视角最大误差为 0.0001221° | 逐帧观察受闪及恢复后一秒的朝向，并检查动画推进、位置、血量、护甲、恢复和清理；失败记录不得省略 |
| 假人及生命周期原生回归 | 假人 64 项、容量 31 项、生命周期 7 项全部通过；容量检查覆盖八个不同俯仰和偏航各自独立保持 | 以当前 RC3 构建的最终执行记录为准 |
| 完整自动检查 | 165 项核心、19 项生命周期/日志/策略、97 项 Python、89 项 Windows 安装器，共 370 项通过；构建零警告、零错误 | RC2 的 370 项通过不计为 RC3 已通过 |

四组闪光回归的动画图实例及序列起点均未重置，动画帧持续推进，视角修正队列没有积累。首次补测曾因诊断弹接触假人而出现 1 点伤害并失败；诊断随后改为在碰撞体外固定真实弹体，保留原生引信、伤害与完整血量断言，上述四组为修正后的最终结果。服务端证据不替代客户端新版本画面验收。

## RC2 历史验证

2026-10-19：构建零警告、零错误；**165 项核心、19 项生命周期/日志/策略、97 项 Python、89 项 Windows 安装器检查，共 370 项自动检查通过**。新增检查覆盖烟雾逆向细化后的完整碰撞回放，以及 Steam 启动参数、已运行游戏分支和客户端资源校验。

RC2 验证使用引擎 **1.41.9.1 / 2000933 / SourceRevision 11133601**，Mirage 无人实例：假人出生/伤害/复位/清理 64 项、八假人容量 30 项、真实闪光连续 3 次各 9 项、生命周期 7 项通过。当时的闪光检查要求原生动画帧实际推进，并检查站位、眼角、血量、护甲、解除致盲和复位；朝向检查未包含身体及原生视角，存在本轮已复现的漏检，不能用 RC2 记录证明受闪时不会转身。

搜索对比使用已发布 RC1 核心和 RC2 核心，固定目标、起点和物理参数，不把生成投法作为提示：

| 对比 | 结果 | 解释边界 |
| --- | --- | --- |
| 312 个固定合成案例 | 原有可用案例和较稳案例均未丢失；2 个案例新增较稳方案；碰撞查询总数由 260,566,156 降至 254,508,448 | 查询工作量减少约 2.32%，不是实投成功率或游戏帧率提升 |
| Mirage 原生碰撞 7 个固定案例 | 前后均有 5 个案例找到候选、4 个有较稳方案；2 个仍未找到；已完成案例的候选数量保持一致 | 同一引擎重新评估历史几何，标记为合成输入；不沿用旧版本的实际可行性证据 |

本次角度逆向细化仅对烟雾启用；闪、雷、火、诱饵继续使用原细化。尝试对所有道具启用的实验曾减少一项手雷案例的较稳结果，已排除该方案。

RC2 发布当时，Steam 启动请求已实际拉起客户端区服选择窗口。桌面工具报告用户输入冲突，未继续操作，因此当时未完成自动连接、客户端遮眼/恢复动作和完整画面流程验收。后续用户已确认受闪动作出现，但发现会自行转身；该反馈触发本轮 RC3 修复。自动连接、完整画面流程及 RC3 朝向修复后的视觉验收仍需分别完成，与 89 项隔离启动器检查分开记录。
