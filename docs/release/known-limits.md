# 已知限制与结果含义

适用于 0.2.0-rc.4。本轮只更新本地工具，发布整理暂缓，仍需要跨电脑和更多真人投掷验收。

## 三种结论分别看

| 结论 | 代表什么 | 还需要什么 |
| --- | --- | --- |
| 找到模拟路线 | 在当前地图碰撞和物理参数下，模拟满足目标条件 | 实际投掷检查 |
| 实际位置命中 | 真实生效点进入目标区域；部分记录还核对了执行动作 | 对封烟、致盲、伤害等效果单独观察 |
| 效果达标 | 对应记录或观察视角满足了需求 | 换视角、换目标或更新游戏后重新检验 |

“较稳”是模型扰动测试的排序，“低容错”是需要更精细操作的候选。它们都不是实际成功率。烟雾落点容差大也不代表一定封满所有视角。

## 路线搜索

- 使用服务器当前地图的原生碰撞查询，但弹道、反弹、摩擦和生效时序由近似模型计算，尚未完整校准。
- 搜索预算有限，复杂多次反弹、狭窄开口、动态门、可破坏物和特殊表面可能漏解或偏离。没有结果不等于无解。
- 跳投、起步投、跑投、静步投等依赖正确的手动执行；准备工具只负责回位、对准和切道具。
- 新移动投以记录的开始操作位置向前助跑 100u，仅接受地面高度偏差不超过 2u 的完整支撑走廊；暂不搜索斜坡、台阶或任意助跑距离。空间检查不等于已校准从静止到指定速度的完整加速过程。
- 不搜索任意连续动作组合，例如所有蹲跳、横移和任意起步时机。
- 同一服务器一次执行一个搜索任务。搜索与显示有逐帧预算，但不能保证所有电脑无帧时间峰值。
- 地图、游戏版本或物理配置变化后，旧路线只在版本条件符合时作为提示，并重新计算；旧记录不自动成为新版验证。

## 道具与效果

| 道具 | 当前边界 |
| --- | --- |
| 烟雾 | 参考轮廓不是完整动态烟幕；封窗反馈仅代表实际观察过的视角 |
| 闪光 | 假人预测依赖距离、朝向和遮挡近似；致盲区间未校准，遮挡不代表绝对安全 |
| 高爆手雷 | 伤害预测是粗估，护甲、遮挡采样和材质会影响偏差 |
| T 火 / CT 火 | 预测接触和参考扩散不等于完整火势；实际火格是有限采样，可能漏掉可行空爆点火路线 |
| 诱饵 | 查找停稳生效位置，不评估诱骗效果或听觉范围 |

效果预览不参与搜索命中评分，不会扩大蓝色目标区，也不直接改变假人血量或闪光状态。无法可靠归属的伤害或燃烧事件会保留为未知，不按距离猜测。

## 界面、假人与兼容性

- 假人身体可见性已有用户实测确认；仍未逐一验收所有地图、观察模式和多人组合。
- 真实受闪动作已有用户画面确认；RC3 同步修正了身体与视角朝向，客户端持续锁向和完整恢复流程仍待复核。
- 菜单、反馈、假人栏需要配套客户端 UI；只装服务器 DLL 不会自动给玩家安装 UI 或按键。
- 地图清单固定为本版本支持的十张官方地图，不承诺支持所有社区地图或实时跟随竞技地图池变化。
- Windows 本地训练是本次主要交付路径。其他操作系统、不同框架版本、第三方插件组合及公网多人部署未完成本版完整验收。
- 工具安装目录须为较短的全英文路径，可以含空格，推荐 `D:\NadeLab`。中文实例路径已出现 Metamod 无法打开插件目录的问题；过长路径也受 PowerShell 5.1 文件 API 限制，安装器会提前拒绝。英文 Steam 游戏源路径已测试，中文源路径尚未验收。
- 游戏或框架更新可能改变原生接口、资源布局和物理表现；更新后应重新执行启动检查并实投验证。

详见 [发布验收清单](release-checklist.md)。发现不符时，可按 [问题反馈](data-and-support.md) 保留必要信息。

## 本地输入模块（2026-11-01 开发版）

仅支持 Windows 上与训练服同一用户的本地客户端。按键文件只读，菜单外滚轮保持个人功能；直接 slot、invnext、lastinv、use weapon 等切换绑定可识别。自定义 cfg 别名、尚未写入配置文件的临时控制台重绑还不能由输入模块完整识别。CS2 原始鼠标输入不能仅靠 Windows 消息拦截阻止，菜单另外在训练服暂时限制可选择装备，关闭后恢复。普通关闭、补给切出与人为清空装备槽的恢复已验证；任意第三方插件同时改库存的组合仍未完整验收。聊天、控制台、失焦或训练状态超过 700ms 未更新时停止接管，并解除菜单装备限制。此模块不用于远程公共服务器；旧安装目录需要单独同步才具备它。
