# NadeLab 玩家手册

本文对应 2026-11-03 的项目开发版。旧安装目录尚未同步，发布仍暂停。请从项目工作台启动训练服与输入模块；独立服务器或未连接输入模块时，按游戏内的降级提示操作。

先记住：**E 下一步，R 下一投法，F1 菜单；滚轮或 ↑↓ 选择，E 确认，R 返回。** 输入模块只在当前本地训练连接和 CS2 前台接收这些按键，不改个人键位文件。关闭菜单后滚轮恢复个人功能，切屏、断开连接、聊天或控制台输入时暂停接管。

## 完成第一次投掷

1. **选择道具。** F3 循环选择烟雾、闪光、手雷、T 火、CT 火或诱饵。F3 不打开选择菜单；需要直接选择时，从其他设置进入原有道具选择页。
2. **选择目标。** 关闭菜单，烟、火、诱饵把准星指向地面后按使用键。闪光、手雷在出手位置站稳后按使用键，变成道具模型，飞到想要的爆点，再按使用键确认返回；换弹键取消。
3. **选择出手位置。** 到想投掷的位置，V 退出飞行，落地站稳，关闭菜单后按 E 搜索。已经记录过站位时沿用记录；想换成当前位置，按 Shift+R，目标保留。
4. **准备。** 找到投法后按使用键，工具回位、对准视角、切出对应道具。等屏幕确认准备完成，再按提示蓄力并手投。
5. **比较。** 换弹键切下一种投法并就位；使用键重试当前投法。实际落点正确后，再观察是否封满、烧到、造成伤害或致盲。

本文后续所说“使用键 / 换弹键”，在输入模块连接时分别指 E / R；降级模式则按个人对应的游戏动作绑定。

投掷前关闭菜单。蓄力或正在出手时，部分训练操作会暂停，松键投出后再切换方案。

区域草稿须先应用或取消，飞行时先落地站稳再记录投掷站位；屏幕按当前状态提示可用操作。

## 不输入命令检查按键

选择 **F1 → 其他设置 → 检查菜单按键**，分别滚动滚轮和按 ↑↓。上方提示栏显示本次收到的操作；E 或 R 结束检测，不修改目标与站位。每次重新打开都重新计数。“未收到”表示本次未收到输入，不能直接判定按键故障。

底部操作区只放当前动作、菜单选项和快捷键。上方反馈区用“反馈 / 说明 / 状态”区分操作结果、当前选项的条件及实时进度；保存成功或失败不会挤走菜单。短反馈到期后恢复当前状态，搜索和组合加载进度会持续更新。投掷时机与菜单关闭时的未就绪原因优先显示。假人实测和预测继续留在独立假人栏，完整记录在详情页查看。

菜单与反馈框位于屏幕下方居中，主菜单六项完整显示，子菜单五项随选择滚动。正文 17px、快捷键 12px，快捷键占独立的两行。返回上一级保留选中项，收藏详情返回原类别和分页；删除确认默认选择取消。更新面板资源后需退出并重新打开 CS2，重连服务器不会清除客户端缓存。

F5仅在本地输入模块连接且存在自己的假人时提供，道具定位和组合加载期间不提供。复位保留假人原位置、朝向和寻闪要求，恢复血量并清除致盲与实测记录；搜索、创建或实投观测仍在进行时提示等待。这个快捷键不写入个人绑定；旧兼容模式仍按其原有F5定义操作。

主菜单固定为：**当前任务、目标与站位、假人与寻闪、我的道具库、切换地图、其他设置**。当前任务的文字会说明下一步；无敌是训练模式的固定状态，飞行和显示开关放在其他设置。

实投小窗采用 A 组原生持续开启方案，在 **其他设置 → 显示设置 → 飞行小窗** 开关。连续投掷不再等待旧道具全部结束才恢复；镜头仍由游戏控制，旧烟生效可能打断新画面，也不保证每次跟随最新一颗。这不是独立相机方案，尚无“连续投掷无卡顿”的客观帧时间验收结论。

主菜单的 **换弹是关闭**，子菜单和详情页的 **换弹是返回**；关闭菜单后有投法时，换弹键才是下一投法。底部按键随所在步骤更新，临时反馈不再重复这类可能随菜单改变的键位。

## 按需求找功能

| 需求 | 路径 | 操作结果 |
| --- | --- | --- |
| 更换出手站位 | Shift+R；或菜单 → 目标与站位 → 从当前位置重新搜索 | 保留目标，重新记录当前位置并搜索 |
| 选择竞技出生位 | F1 → 目标与站位 → T / CT 出生位 → 选择编号 | 仅列出5v5竞技可选的出生位；现场常驻绿色地面方框与数字，两侧各自编号。选中后精确就位并恢复出生朝向，保留目标和假人要求、取消旧站位投法、退出飞行，不改变队伍。关闭菜单后地框仍保留 |

出生位按地图原生优先级选取5v5候选池，同一优先级的可选位全部保留，不会只取任意5个。未启用和比赛用不到的备用位不显示。当前 Mirage 为 T 10 / CT 5，Dust2 为 T 15 / CT 5。采用 NadeLab 自身坐标排序编号，未对照完美平台；本次剔除备用点后，编号较旧版有变化。同一地图候选池内重进地图、有人占位都不会重排；地图更新增减或移动点位可能改变编号。被占用或站立空间不足时明确提示，不会偷偷换点。绿色地框与数字在训练中常驻，所有训练玩家可见；换图、关闭训练模式或卸载时清理。
| 更换目标 | 菜单 → 目标与站位 → 重选目标 | 清除旧方案；已有站位尽量保留 |
| 允许落在一片区域 | 菜单 → 目标与站位 → 调整允许落点范围 | 调整蓝色区域；烟雾还可添加多个允许区和排除区，应用后生效 |
| 研究 Mirage VIP 烟 | 菜单 → 目标与站位 → VIP 窗口烟预设区域 | 选定预设落点区域，封窗仍需实投观察 |
| 优化刚才的优质手投 | 菜单 → 目标与站位 → 采用最近实投爆点 | 采用自己的当前道具真实事件位置，保留已记录站位 |
| 寻找其他路线 | 菜单 → 其他设置 → 研究工具 / 实投证据 → 继续寻找更多路线 | 延续搜索与复核，尝试更多方向和动作 |
| 允许工具尝试附近位置 | 菜单 → 其他设置 → 研究工具 / 实投证据 → 允许附近换站位搜索 | 明确允许偏离原站位，检查附近可站位置 |
| 无解也想记录自己的投法 | 菜单 → 其他设置 → 研究工具 / 实投证据 → 记录自由实投 | 限时记录手投，供对比分析 |
| 查看动作、角度、实测 | 菜单 → 其他设置 → 研究工具 / 实投证据 → 路线证据 / 实投反馈与保存 | 查看当前方案执行建议及证据，满足条件后保存 |
| 关闭线条或提示 | 菜单 → 其他设置 → 显示设置 | 分别控制轨迹、松键标记和提示 |
| 换地图 | 菜单 → 切换地图 → 选择 → 确认切换 | 清空本轮训练状态；保留已保存数据 |

范围编辑期间要明确选择“应用”或“取消”。在编辑主页按换弹只是关闭面板并保留草稿，可从菜单 → 目标与站位 → 调整允许落点范围继续编辑。

烟雾可进一步标记想封住的窗口：菜单 → 目标与站位 → 调整允许落点范围 → 多个落点区 / 排除区 / 封窗标记 → 形状、高差 / 封窗与观察点 → 标记要封住的窗口 / 观察点。按提示依次选择竖直窗框正面的两个对角，再记录观察位置和朝向，返回应用。需要移动观察时，返回主菜单开启飞行，关闭菜单后移动，再通过“调整允许落点范围”返回草稿。紫框是搜索提示，不强制弹道穿框；实际封满仍需投烟后观察并反馈。

切换道具时，兼容的简单目标可以保留；地面/空中类型变化，或目标含多个区域、排除区及封窗标记时，会要求重新选点，避免留下看不见的旧限制。

## 看懂搜索结果

优先尝试和低容错方案在同一列表，优先展示操作较简单的已复核方案。“低容错 · 待实投”也可直接准备、切换，需要更仔细地执行。角度、站位、速度和松键时机分别检查，单项薄弱不会被总分掩盖；“模型待验证”单独提示出手模型敏感。这些指标来自有限的模型扰动测试，不是实战成功率。烟雾以落入选定区域为主要判据，封满或漏缝保留为人工观察记录。

新搜索记录的是**开始操作的位置**。移动投就位回到这个起点，从这里沿指定视角向前助跑 100u，到标记处松键；助跑跳投则在标记处起跳并松键。准星下方的小条显示移动按键、距松键位置的距离和提前准备提示，无需低头看脚下。只有速度、方向满足已采样窗口时才显示“进入采样区”；它不是自动投掷或真人成功保证。菜单打开、离地、切走道具或投出后隐藏。切换候选不会再按不同方向退到另一个助跑起点。站投和原地跳投仍在记录点执行。旧搜索记录和旧路线保留原来“出手基准、后退助跑”的含义，不会自动改写；使用 Shift+R 从当前位置重新搜索即可采用新模式。

移动投仅接受有完整支撑、无人物碰撞且近似平坦的前向路径，台阶和斜坡可能无法给出此类候选。100u 是固定助跑距离，仍需按屏幕要求控制速度并实投验证。

需要直接选较后面的投法时，进入 **F1 → 当前任务 → 路线列表**。每页五项，通过“上一页 / 下一页”翻页，选中条目后就位；翻页本身不切换当前投法。R 仍可依次循环全部结果。列表优先列出较好操作的路线，但编号保持不变，数字不连续是正常的。普通搜索优先尝试、低容错两类各最多保留 24 条；按假人寻闪最多保留 24 条，实际数量取决于本次通过复核的结果。“继续寻找更多路线”保留当前路线并补充结果，数量限制不代表地图理论可行解的总数。

搜索中出现已复核路线后，可立即选择“采用路线”或关闭菜单按 E/F6 就位，**后台继续寻找，不必等整轮结束**。新增结果不会换掉你正在练习的方案、编号和实投记录。“停止搜索”保留已找到的路线。开始手投前仍要等待当前碰撞路线、站位、角度和道具检查就绪；若路线已变化会明确提示重新选择或搜索。朝天、操作敏感或近乎重复的路线不会单独触发提前结束；补找仍有数量和时间预算。没有结果可以继续搜索、适度放宽符合需求的目标区域，或换站位；未命中只表示本次没有找到。个人库可提供线索，但不作为工具必须先收录才能找出路线的前提。

## 按假人要求找闪光投法

选择 **菜单 → 假人与寻闪 → 按假人找闪：要闪 / 不闪**，不需要指定爆点。

1. 先放置假人，朝向代表爆炸时希望它看的方向。
2. 从寻闪主页选择 **设置假人要求 / 假人要求** 打开列表，逐个选择“要闪”“不闪”或“不参与”。至少设置一个“要闪”。修改后仍选中刚才的字母，方便继续设置下一个；换弹键返回寻闪主页。
3. 回到投掷位置落地站稳，选择“从当前位置找投法”，或关闭菜单按使用键。
4. 工具固定本次站位搜索静投、原地跳投、三种力度及反弹路线。使用键准备候选、换弹键下一候选；自己蓄力手投。
5. 假人栏逐个显示预测或本次实测；寻闪菜单 → 查看预测与本次实投，查看完整结果。结束观测后，可从寻闪菜单选择“复位我的全部假人”，再按使用键准备下一次测试；原姿态和身份未变时保留已有投法。Shift+R从新位置重搜，寻闪菜单 → 更多：换站位 / 指定爆点 → 切回指定爆点。

当前站位附近有同版本的个人闪光实投收藏时，搜索会优先尝试收藏瞄点，再按当前假人要求重新筛选。不会移动到收藏位置，也不会把收藏直接判为合格；动作不明时比较现有站投/原地跳投力度组合。

寻闪主页集中显示当前步骤、要求、复位和组合；换地图与其他设置也可返回主菜单进入。没有假人时优先显示放置与加载入口。

“要闪”首版按原生致盲事件至少 1 秒判定，这不等于全白 1 秒。“不闪”候选需通过多条眼位遮挡检测，仍不保证实际安全；手投后只有完整观测未出现致盲才显示本次达标。任一保护对象被闪就会显示未达标，其他人的较好效果不能抵消。事件缺失、朝向变化、其他闪光干扰会记为未知。假人姿态改变需重搜，投掷者自身不会自动获得保护。搜索未找到不表示理论无解。

## 闪光与手雷：用道具本体选爆点

菜单 → 目标与站位 → 重选目标，进入定位，道具本体当前位置就是爆点。转视角或定位菜单 → 切换第一 / 第三人称不会改变爆点。手上的其他库存暂时隐藏，退出定位后恢复。

步行站稳后进入定位，确认时采用进入前的位置作为出手站位。飞行中进入则保留原有站位，返回后仍是飞行；从菜单退出飞行、落地后再准备投掷。换弹键取消保留原目标和方案。返回位置被占用时，可在空处按换弹键取消并保持飞行。

定位默认开启效果预览，可从定位菜单开关：爆点轻微脉冲，假人状态栏显示“预闪”或“预雷”。这些是近似效果预测，不造成真实伤害或白屏；离开定位后清除。关闭效果预览时保留基本定位十字。

## 测试假人

**保存组合：菜单 → 假人与寻闪 → 假人组合：保存 / 加载 → 选择组合槽 → 保存当前假人。** 每位玩家在每张地图有 8 个槽，每槽最多 8 个假人。恢复时保留 A–H 字母和颜色、位置、朝向、护甲设定，以及“要闪 / 不闪 / 不参与”要求。

加载会替换自己的全部假人，恢复为 100HP，不恢复之前的受伤和致盲。先离开保存的站位，避免挡住生成位置。工具会先检查位置与全服人数上限，再逐个加载；加载中可从组合菜单停止，保留已经就位的假人。换图和重启后仍可载入当前地图的组合，其他玩家的假人不会被替换。覆盖保存保留上一次文件备份。

1. **F1 → 假人与寻闪 → 连续放假人**，进入一次即可。
2. 到观察点站稳，朝向希望假人观察的方向，按 E 记录。
3. 离开记录位置至少 48 个游戏单位，按 E 放置，等待提示完成。
4. 到下一处重复 E 记录、移开、E 放置。R 取消当前记录，再按 R 结束；创建失败保留记录，修正后可重试。**每人最多 8 个，全服共享 8 个名额**。

管理入口为 **假人与寻闪 → 查看 / 复位 / 删除假人**。删除会再次确认，取消优先。道具库按当前地图分组，类别使用“烟雾弹、燃烧瓶 / 燃烧弹、手雷、闪光弹、诱饵弹”，不使用“烟区、雷区”等名称。

假人按 **A 红、B 蓝、C 绿、D 黄、E 紫、F 青、G 橙、H 白**区分，世界标记和状态栏使用同一标识。删除中间一个不会让其余假人重新编号。

假人固定站位和朝向，无武器，可以掉血、死亡和受闪。自己的全部假人显示在独立状态栏，每个一行；实际血量、护甲和最近效果与“预闪/预雷”分开。没有测得事件不等于没有受到影响。

按假人找闪时也持续显示当前 HP、护甲、掉血与剩余致盲时间；右侧附加要闪/不闪要求和预测或本次记录。“记录闪”是已测得的事件，不是当前仍在致盲；当前状态看前面的致盲倒计时。变为道具预览时优先显示当前位置的预测，复位后恢复实况并清除旧记录。

从“准星选择我的假人”或“选择列表”选择对象，再复位或删除；复位恢复其原位置、100 HP 和设置的护甲，也清除闪光及测量历史。可对自己的全部假人批量操作。真实受闪动作已有玩家确认；RC3 修正受闪后的自行转身，持续锁向及完整恢复画面仍待复核。

## 范围与线条

| 显示 | 含义 |
| --- | --- |
| 蓝色实线 | 搜索允许的落点/爆点区域，从“调整允许落点范围”编辑 |
| 红色实线 | 排除区域，落入其中不算命中 |
| 紫色框 / 金色短线 | 烟雾封窗标记 / 预设观察方向 |
| 灰色虚线 | 烟体范围参考，不保证封满 |
| 橙色短线 | 火焰扩散参考，不保证烧到 |
| 绿色火格十字 | 最近一次实测燃烧采样点，不是完整火区边缘 |
| 白色 / 橙金脉冲 | 闪光 / 手雷定位爆点，不是伤害边界 |
| 绿色地面短线 | 移动投的松键位置或区间 |
| 淡黄色轨迹 | 当前方案的预测路线，默认关闭 |

烟火效果参考默认关闭，可从菜单 → 其他设置 → 显示设置：范围 / 轨迹 / 提示开关。有方案时围绕预测生效点，只有目标时围绕目标中心，两者都没有时跟随准星。提示框会说明当前参考位置；编辑目标或蓄力时部分辅助线暂时隐藏。诱饵没有效果范围。各玩家只应看到自己的辅助线；多人场景仍需进一步验证。

## 换地图与结束训练

支持的十张地图见 [README](../../README.md)。菜单只提供已安装的图，切换需要再次确认；多人训练需要管理员切图权限。换图会清除本轮目标、站位、搜索、假人和定位状态，已保存记录保留。

训练玩家受到正常伤害时保持无敌，假人正常受伤。无限热身由训练配置启用。结束后断开连接，使用 NadeLab 工具停止本地训练服；更新 CS2 前也先停服。

## 可选：旧快捷键兼容模式

仅需要旧方案时，在安装命令中明确使用 `-LegacyBindings`。它会为所选资料备份原键位并设置入口，启动时加载旧训练配置；具体操作见 [安装与恢复](install-and-recovery.md#可选旧快捷键兼容模式)。默认输入模块不启用以下绑定；下述兼容模式不属于本轮推荐方案。

兼容配置覆盖 14 个键：F1–F9、↑ / ↓、滚轮上 / 下及 V。F1 重新加载旧配置并开关菜单；F2 编辑范围（寻闪时打开假人要求），F3 换道具，F4 效果参考或结果，F5 重选目标，F9 切定位镜头，V 飞行。F6 / F7 / F8 在菜单外为下一步 / 下一投法 / 换站位，菜单内为上 / 下 / 确认；滚轮和方向键用于菜单选择。兼容模式会占用个人原有的这些功能，包括滚轮跳。

需要恢复时，退出游戏后使用工具的恢复入口，按安装记录仅还原仍由 NadeLab 占用的键，保留后来改过的绑定。不要将兼容配置写入日常 autoexec，也不要拿另一账号的备份恢复当前账号。
