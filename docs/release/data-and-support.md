# 数据与问题反馈

## 数据保存在哪里

本地工具把运行实例放在解压目录的 `instance/`，安装记录和备份放在 `release-state/`。插件数据位于训练实例的：

```text
game/csgo/addons/counterstrikesharp/plugins/NadeLab/data/
```

独立训练服也使用这个插件数据目录。它保存搜索、手投、效果事件、最近爆点、路线库和另存的投法。升级前完整备份 `data/` 与自定义 `physics.json`；切图不会删除这些文件。

记录可能包含 SteamID、投掷时间、地图与版本、位置、视角、动作、轨迹和效果信息。最近实投爆点按账号及版本恢复，不会把别人的爆点给当前玩家使用。这里的记录是本地研究数据，不会因搜索而自动公开。

## 反馈时附什么

优先提供这几项：

1. NadeLab 版本、CS2 版本、地图、选用的道具和动作。
2. 发生问题的步骤，屏幕或控制台的完整错误文字。
3. 问题是否每次出现，是否只在搜索、开菜单、切图或使用假人后发生。
4. 路线问题附出手站位、目标区域、候选类型和一段实际投掷录像；界面问题附分辨率与截图。
5. 工具的状态输出；需要日志时只提供相关时间段。

搜索漏解时，能手投成功的录像或“自由实投记录”很有帮助。它能区分漏搜、物理偏差和执行动作偏差。

## 分享前检查

不要公开 RCON 密码、服务器访问密码、Steam 用户目录、完整安装备份或未经筛选的全部日志。分享数据副本时可替换 SteamID，保留同一玩家在记录中的一致标识；不要改动事件的坐标、时间间隔和道具类型，否则难以复现。

当前发布包不包含专用的一键匿名化导出工具。不要把整个 `instance/`、`release-state/` 或插件 `data/` 当作问题附件上传。

删除数据前先停服并自行保存需要的投法。数据目录删除后，历史爆点、投法证据和实投记录无法由工具恢复；客户端按键恢复不需要删除这些训练数据。
